# Problem brief

| Field | Working answer |
|---|---|
| Decision and owner | What decision is needed, by whom, and when? |
| Observable problem | What is happening, to whom, where, and when? |
| Evidence and baseline | Source IDs, population, time window, measurement limits |
| Desired outcome | Observable change; proposed versus agreed target |
| Scope | Included/excluded actors, processes, and systems |
| Constraints | Restrictions and their sources |
| Assumptions | Unverified claims and how to test them |
| Alternatives | Credible responses and trade-offs |
| Next step | Smallest useful action, owner, and review trigger |
