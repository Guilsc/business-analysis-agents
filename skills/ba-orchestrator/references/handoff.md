# Handoff contract

## Brief
```text
Goal and decision:
Selected role / skill path:
Scope and exclusions:
Input artifacts / IDs / versions:
Known evidence and its source:
Assumptions and open questions:
Deliverable and audience:
Acceptance criteria:
Allowed tools, writes, and external actions:
Required dependencies:
```

## Return
```json
{
  "role": "ba-problem-framing",
  "status": "needs-input",
  "artifacts": [],
  "evidence_used": [],
  "assumptions": [],
  "open_decisions": [],
  "recommendation": "",
  "next_role": null,
  "checks_performed": []
}
```

Use `complete`, `partial`, or `needs-input` accurately. Equivalent Markdown is acceptable. An artifact is complete for the delegated task only when its acceptance criteria are met; this does not establish implementation or business success. The orchestrator resolves shared-file versions and conflicts. Recursive delegation requires explicit delegated authority.
