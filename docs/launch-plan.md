# Launch and discoverability

## Positioning
Business Analysis Agents helps people move from an ambiguous request to evidence, clear requirements, and a reviewable decision. Lead with one practical outcome and the worked example; skill counts alone do not demonstrate usefulness.

## Repository setup
- Use an accurate short description and relevant GitHub topics.
- Keep quick start, role table, example, compatibility, and contribution path near the front of the README.
- Publish tagged releases with a concise description of real improvements.
- Add a social preview through GitHub repository settings if desired; the diagram assets are available for adapting one.

## Ethical launch checklist
- Run one realistic case in the host you actually use; show the prompt and useful output.
- Share the example in relevant BA/requirements/AI communities only where their rules allow it.
- Explain limitations and invite reports of unclear behavior.
- Credit related projects and contributors.
- Do not buy stars, automate promotional messages, or imply endorsements.

## What to watch
Look for successful installations, concrete usage reports, repeat contributors, and issues resolved. Stars can signal interest but do not measure decision quality. No growth, accuracy, or productivity improvement is claimed without evidence.
