# Roadmap

## Released foundation
- Nine focused skills, six templates, three workflows, and a fictional end-to-end example.
- Model-neutral role handoffs and portable Markdown documents.
- A dependency-free installer, validator, and CI checks.

## Next, with community evidence
- Run the behavioral cases in different hosts and publish reproducible results.
- Add examples for service changes, data initiatives, and legacy-system migration.
- Improve artifact review with real, anonymized failure patterns contributed under clear rights.
- Add translations maintained by contributors who can review the terminology.

## Contribution priorities
Usable examples and verified behavior come before more role names, provider-specific wrappers, or unmeasured performance claims. Propose a new skill only when the existing roles cannot cover its decision boundary clearly.
