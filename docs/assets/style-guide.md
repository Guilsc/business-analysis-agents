# Repository diagram style

Project-specific tokens: paper `#f8f6f1`, ink `#25392f`, muted `#53685a`, accent `#9d3c23`, accent tint `#f5e5dc`.

Use one focal node, warm white card fills, orthogonal connectors, and no shadows. Labels describe responsibility or decisions. These diagrams use local system-font fallbacks (Cambria/Georgia, Segoe UI/Arial, Consolas) for offline rendering rather than downloading the upstream typefaces. HTML is the maintained source; PNGs are browser exports for GitHub.

Type selection: the role map uses an architecture layout with nine nodes and eight routes; it shows selectable capabilities rather than active runtime processes. The working loop is a five-stage process. Neither picture is evidence that external agents executed.
