# Content provenance

The public toolkit was authored around common analysis jobs: framing problems, gathering evidence, specifying behavior, comparing choices, improving processes, assessing changes, reviewing outcomes, and communicating models.

Its skills, templates, handoff contract, and Northstar Support example were written for this repository. The example organization and records are fictional. No stakeholder interviews or pilot results are claimed to have occurred.

An earlier private book-conversion exercise motivated the project idea. The source book, raw extraction, chapter references, and chapter-by-chapter conversion are excluded from this public repository. This toolkit does not claim to reproduce or comprehensively cover that publication.

The diagram examples use the design approach of Cathryn Lavery's MIT-licensed diagram-design project. That dependency is linked rather than vendored. See NOTICE.md for attribution.

Compatibility documentation links to each host's primary documentation. It distinguishes documented placement conventions from runtime behavior actually tested. Version 0.1.0 has local packaging, installer, and diagram-render checks; live cross-host behavioral results are future work.
